# MRO 业务管理（网页版）

小公司内部用的 MRO 物资业务系统，8 个模块全在一个页面里。纯静态网页，不需要服务器、不需要数据库、不需要域名。

## 打开方式

仓库启用 GitHub Pages 后访问：

```
https://jianqiyue.github.io/mro-business/
```

启用步骤（只做一次）：仓库 Settings → Pages → Source 选 “Deploy from a branch” → Branch 选 `main` / `(root)` → Save，等 1~2 分钟。

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架（侧边栏、搜索框、新建弹窗） |
| `style.css` | 全站样式 |
| `schema.js` | 8 大模块与字段定义（改字段名、改下拉选项只改这里） |
| `seed.js` | 示例数据 + 本地存储读写 |
| `app-core.js` | 工具函数、侧边栏、工作台统计 |
| `app-ops.js` | 列表、新建/编辑弹窗、删除、付款审批、导入导出 |

## 功能

- **工作台**：本月报价数、中标数、成交额、待付款额自动汇总；待办合并合同到期、报价未跟进、付款待审批
- **客户 / 供应商档案**：增删改查 + 全局搜索
- **货源比价**：同一物料多平台录入，自动找出最低价并算价差
- **投标管理**：平台、报名截止、开标日、保证金、结果
- **报价单**：毛利率自动计算
- **合同**：到期提醒进入工作台待办
- **付款申请**：待审批 → 一键审批 → 待付款 → 已付款，自动记录动态
- **导入 / 导出**：JSON 全量备份恢复；按表导出 CSV（带 BOM，Excel 直接打开不乱码）

## 数据存在哪里

数据存在**浏览器 localStorage**，每台电脑/浏览器各自一份，刷新不丢，但**不同人之间不互通**。
要 6 人共享同一套数据，需要接后端（如 Supabase 免费版），或者改回用飞书多维表格。
跨设备迁移：左侧「导出数据」→ 另一台「导入数据」。

## 怎么改内容

1. 登录 GitHub，打开对应文件，点铅笔图标直接改文字/选项，Commit；1 分钟后网页自动更新。
2. 或在仓库页按 `.` 键进入 github.dev 在线编辑器，像 VS Code 一样改完提交。
3. 也可以直接把改动需求告诉 AI，由 AI 提交。

## 注意

- 仓库是 public，网页公开可访问，但里面只有演示数据；真实客户资料不要写进代码，只在自己的浏览器里录入。
- 清浏览器缓存会丢数据，定期「导出数据」备份。
